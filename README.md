# 成都文理学院魔方社网站（课程设计第二版）

## 如何运行
1. 解压整个项目文件夹。
2. 直接双击 `index.html` 用浏览器打开即可预览（图片全部是本地相对路径，无需服务器）。
3. 推荐 VS Code + Live Server，或任意静态服务器：
   - Python：`python -m http.server 8080`，然后访问 `http://localhost:8080`
   - Node：`npx serve .`

## 3D 魔方实现原理（答辩可讲）
- **结构**：27 个 `div.cubie`，每个内含 6 个 `div` 面，用 CSS 3D transform
  （`rotateX/rotateY + translateZ`）拼成正方体；处于外表面的面加 `out` 类贴彩色贴纸，
  内部面保持塑料黑色，所以拧动时切面是黑色的，和真实魔方一致。
- **状态**：每个小方块记录网格坐标 `p`（-1/0/1）和姿态矩阵 `m`（3×3 整数矩阵）。
- **拧层**：一次 90° 转动 = 该层 9 个小方块的 `p` 和 `m` 左乘一个 90° 整数旋转矩阵
  （无浮点误差累积），动画用 CSS transition 在新旧 `matrix3d` 间平滑过渡。
- **视角**：外层 stage 容器 `rotateX(rx) rotateY(ry)`；自动旋转即每帧给 `ry` 加 0.12°，
  拖动空白处按增量修改 `rx/ry`。
- **手势判定**：按在色块上拖动 → 拧层；按在空白处拖动 → 转视角。
  拧层方向用向量叉积 `ω = 面法向 × 拖动方向` 求出旋转轴，再吸附到最近坐标轴，
  层号取被点击小方块在该轴上的坐标。详见 `js/cube.js` 顶部注释。

## 计时器说明
页面通过 iframe 嵌入 csTimer 中文页面（开源第三方工具），并保留"在新页面打开"按钮备用。
参考：https://cstimer.net/new/?lang=zh-cn ｜ https://github.com/cs0x7f/cstimer

## 部署到服务器
整个文件夹是纯静态站点，把 `index.html`、`css/`、`js/`、`assets/` 原样上传到任意
虚拟主机 / 对象存储 / Nginx 静态目录即可，无需后端。注意保持目录相对结构不变。
